TREX AI - USER GUIDE

Welcome to TreX AI, your personal desktop voice assistant.
TreX helps you control your computer, open apps, search the web, and perform tasks using simple voice commands.

---

GETTING STARTED

1. Install TreX using the setup file (TreX_Setup.exe).
2. After installation, open TreX from desktop.
3. TreX will start in the background.
4. To wake it up, say:
   "Hi TreX"

Once activated, TreX will listen to your commands.

---

WAKE & SLEEP

Wake TreX:

* "Hi TreX"
* "Hey TreX"

Put TreX to sleep:

* "Sleep"
* "Go to sleep"

---

BASIC COMMANDS

Open Apps:

* "Open Chrome"
* "Open Notepad"
* "Open Camera"
* "Open Spotify"

Close Apps:

* "Close Chrome"
* "Close Notepad"
* "Close VLC"

Note: Speak clearly. If TreX doesn’t respond, try again with proper pronunciation.

---

WEB COMMANDS

Open Websites:

* "Open YouTube"
* "Open Instagram"
* "Open Gmail"

Search Google:

* "Search Python tutorial"
* "Search best laptops under 50000"

Search YouTube:

* "Search YouTube coding tutorial"
* "YouTube search funny videos"

---

FILE & SYSTEM COMMANDS

Open Drives:

* "Open C drive"
* "Open D drive"

Create Folder:

* "Create folder Test"
* "Create folder Projects"

Startup Control:

* "Startup on"
* "Startup off"

---

SMART USAGE TIPS

* Always speak naturally.
* Avoid background noise.
* Use simple words.
* If command fails, repeat slowly.

---

UPDATE TREX

To update TreX, say:

* "Update TreX"

TreX will download the latest version.
After download:

* Open the new file
* Replace or delete the old version manually

---

TROUBLESHOOTING

If TreX is not responding:

* Restart the application
* Check your microphone
* Speak clearly

If app doesn't open:

* Try again with correct name

---

IMPORTANT NOTES

* TreX runs in background
* No terminal window will appear
* Internet is required for AI responses

---

FINAL

TreX is designed to make your computer easier to control using voice.
Keep exploring commands and use it daily for best experience.

---

Enjoy using TreX AI 🚀
